# Moto WOW
Standalone browser racing game. Do not modify other MAINBOTS projects.
Node >=22.13, Three.js + Vite client, Express/WebSocket authoritative server, SQLite.
Physics and circuit definitions live in shared/. Server owns online lap timing.
Run npm test, npm run build, npm run test:e2e for gameplay/network changes.
Keep asset authors/licenses in docs/ASSETS.md. Do not claim manufacturer accuracy for original approximations.
