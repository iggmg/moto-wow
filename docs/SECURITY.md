# Проверка публичной версии — 7 октября 2026

Публикуется статический клиент и отдельная проверенная копия исходников. Онлайн-сервер пока запускается локально: его размещение в интернете отложено. На GitHub Pages без игрового сервера доступны одиночные заезды и местные рекорды; регистрация и друзья требуют сервера.

## Приватность

- В HTML, JS, моделях, текстурах и шрифтах публикационной сборки проверяются имя локального пользователя, пути личных каталогов, шаблоны токенов и приватных ключей. Запрещены .env (кроме образца), SQLite, журналы и карты исходников.
- В публичные исходники попадают только разрешённые каталоги проекта. Локальные журналы, тестовые снимки, данные аккаунтов, фотографии пользователя и старая история Git исключены. Первую публичную историю следует создать с нейтральным автором; GitHub-аккаунт и адрес репозитория остаются публичными по правилам самого GitHub.
- Проверка по шаблонам не может выявить любую произвольную личную информацию. Дополнительно просмотрены тексты интерфейса и документации, конфигурация, список файлов. Названия авторов сторонних ассетов и лицензии сохраняются.
- Форма аккаунта просит только выдуманный ник и отдельный пароль, предупреждает не использовать реальные имена, контакты и повторные пароли. Аналитики и сторонних шрифтов нет.

## Защита

- Пароли: scrypt, отдельная случайная соль; сессионные токены случайные, в базе только SHA-256. Cookie HttpOnly; максимум пять сессий на пользователя. Токен клиента живёт в памяти, а не localStorage.
- POST API требует разрешённый Origin и JSON. Ограничены размер тела, попытки входа, общее количество запросов и одновременно выполняемые проверки паролей.
- WebSocket требует разрешённый Origin и одноразовый билет на 15 секунд. Ограничены число соединений, размер сообщения, частота, время входа и исходящий буфер. JSON null, массивы и некорректные формы отклоняются без падения процесса.
- Сервер принимает только управление. Позиция, здоровье, орки, погода, результаты и права создателя комнаты определяются сервером. Круг засчитывается после всех контрольных точек по порядку.
- Динамические ники выводятся через textContent; SQL использует подготовленные параметры. CSP запрещает внешние скрипты и встраивание объектов; есть политика no-referrer. Отладочный доступ к состоянию игры отсутствует в публикационной сборке. Сервер добавляет дополнительные защитные заголовки; ограничения платформы GitHub Pages нельзя заменить HTML-метатегом.
- npm audit: известных уязвимостей на дату проверки не найдено. Проверки запускаются повторно при обновлениях; в публикации также проверяется пакет файлов.

## Границы

Это не гарантия неуязвимости и не независимый аудит. Изменение собственной локальной тренировки возможно; такие результаты не входят в серверный рейтинг. Публичный сервер требует HTTPS/WSS, ограничения на входящую нагрузку у хостинга, отдельный диск, приватные резервные копии и нагрузочную проверку. За обратным прокси лимиты приложения сейчас общие для его адреса: перед массовым запуском нужен доверенный прокси и отдельные лимиты на реальные адреса пользователей. Нельзя считать эти меры защитой от любого DDoS или уязвимости браузера/хостинга.

Основные рекомендации: [OWASP WebSocket Security](https://cheatsheetseries.owasp.org/cheatsheets/WebSocket_Security_Cheat_Sheet.html), [OWASP CSP](https://cheatsheetseries.owasp.org/cheatsheets/Content_Security_Policy_Cheat_Sheet.html).
