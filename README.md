# Мотогонки в WOW — Moto Rift

Браузерная 3D-гонка в собственном фэнтезийном мире: лес, руины, портал, орки, грунт и грязь. Четыре извилистые трассы, шесть мотоциклов, аркада, стант, чемпионат и комнаты до восьми игроков.

Это независимый проект по мотивам фэнтезийной эстетики. Ассеты Warcraft не используются. Названия мотоциклов обозначают прототипы; авторские модели приближённые, не официальные заводские модели и не фотограмметрия.

## Что работает

- Honda CUB, Yamaha Exciter, Royal Enfield Himalayan, Honda Winner, Honda PCX, Yamaha MT-07: шесть отдельных авторских моделей, PBR-материалы, экспортированные GLB и разные настройки движения.
- WASD / стрелки: газ, тормоз, поворот; пробел: тормоз. C: переключение камер. R: возврат к последней точке (+5 с). Esc: гараж. На телефоне — кнопки газа/тормоза/поворота.
- Грязь уменьшает скорость и сцепление; бездорожье замедляет; столкновения с камнями, брёвнами и орками дают +2 с и сбрасывают скорость.
- Орки замечают гонщика, преследуют и атакуют при сближении. Остановившегося замечают с расстояния до 90 м, движущегося — до 36 м. От погони можно уйти на скорости; орк прекращает преследование за пределами своей области и возвращается к патрулю. Предупреждение и красные отметки на миникарте показывают опасность.
- Орки с текстурами и скелетными анимациями стреляют из луков, бросают копья и камни. Снаряды летят по траектории и могут промахнуться; предупреждение показывает замах.
- Два трамплина с настоящим отрывом от земли и приземлением, два речных брода, песчаный участок. Ясно / дождь / снег выбираются перед тренировкой; первый участник комнаты задаёт общую погоду. Дождь уменьшает сцепление, снег меняет покрытие и вид мира.
- Контрольные точки нужно пройти по порядку. В HUD: здоровье, текущий/лучший/прошлый круг, штрафы, покрытие, миникарта, участники комнаты.
- Тренировки доступны без аккаунта. Их рекорды сохраняются только в этом браузере.
- Регистрация только по выдуманному нику и отдельному паролю (в форме предупреждение о личных данных и повторном использовании паролей), вход, выход, серверная таблица лучших кругов по мотоциклам. Онлайн-рекорды измеряет сервер.
- Три режима: одному на 1/3/5 кругов (по умолчанию 3), открытая трасса со свободным присоединением, гонка с друзьями по коду комнаты и общим трёхсекундным стартом. Создатель запускает заезд и собирает следующий.
- Здоровье: 100 единиц. Стрела −12, копьё −20, камень −16, удар орка −20; урон от камня/бревна зависит от скорости. Между попаданиями 1,8 с защиты. При нуле гонка прекращается; на открытой трассе возвращение через 5 с, в гонке — после завершения заезда. Возврат R не лечит.
- Детализированный лес: ветви и листва вместо конусов, папоротники и трава; текстуры коры, грунта и камня, колеи и лужи, каменные руины и ограждения.
- Гонщик в экипировке с полноценным шлемом, визором, перчатками и ботинками; объёмные обтекатели, крылья и детали двигателя.
- Два вида камеры, звук двигателя, шин, ветра и столкновений при старте (есть выключатель), адаптивное снижение разрешения при низкой частоте кадров, встроенные локальные шрифты.

## Извилистые трассы и навигация

Четыре разных замкнутых маршрута: плавные S-повороты в Изумрудной Долине (около 755 м), лесные петли Сумеречного Разлома (1,14 км), Речные Петли с тремя бродами (1,34 км) и горные шпильки Перевала Ледяного Клыка (1,40 км). Перед тесными поворотами нужно снижать скорость; на снегу и под дождём сцепление ниже. Трамплины расположены на плавных подходах. Мини-карта подстраивается под размеры выбранной трассы.

На снегу дорога остаётся темнее окружающего сугроба, а края обозначены оранжевыми отражателями. Стрелка в панели слева указывает путь по дороге, при съезде направляет обратно; при движении против хода появляется «Развернись». Кнопка «Вернуться» переносит к последней пройденной точке со штрафом 5 секунд.

Результаты прежних маршрутов доступны через «Архив прежних трасс». Они не участвуют в рекордах новой редакции. Старой открытой вкладке для онлайн-заезда потребуется обновление страницы.

Мобильные кнопки удерживаются разными пальцами. При выходе пальца за группу кнопок управление отпускается; прерывание касания, уход со страницы и возвращение в браузер сбрасывают нажатия. Нажми заново, чтобы продолжить.

## Локальный запуск

Нужен Node.js 22.13+; рекомендуется Node.js 24 LTS.

```sh
npm ci
npm run server
```

Во втором окне:

```sh
npm run dev
```

Игра: http://127.0.0.1:5173 . Сервер: http://127.0.0.1:8787 . SQLite автоматически создаётся в `data/`; не попадает в Git.

```sh
npm test               # физика, контрольные точки, аккаунты, серверные комнаты
npm run build          # публикационная сборка в dist/
node scripts/audit-public.js # проверка публичной сборки на приватные файлы
node scripts/prepare-public.js # отдельная проверенная копия исходников
npm run test:e2e       # браузерные проверки при запущенных dev/server
npm run export:models # пересоздание оригинальных GLB
```

Для браузерных тестов по умолчанию выбран Google Chrome в macOS. На другой ОС установите браузер и укажите `CHROME_PATH` либо измените executablePath в playwright.config.js.

## Интернет-публикация

GitHub хранит исходники и размещает клиент через Pages; игровой сервер запускается отдельно. Готовы GitHub Actions, Dockerfile и compose.yaml. Подробная инструкция: [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

В настройках репозитория задайте переменную `VITE_API_URL=https://game-server.example` и включите Pages → GitHub Actions. До подключения backend публичная игра работает в режиме тренировки и явно сообщает об отсутствии онлайн-сервера.

## Технологии и ограничения

Three.js/WebGL 2, Vite, Node/Express, WebSocket, SQLite. Фиксированная симуляция 60 Гц; серверные снимки 20 Гц; локальное предсказание движения и сглаживание удалённых мотоциклов. Это аркадная физика, без полноценной модели равновесия двухколёсного транспорта. Время и рекорды считаются сервером, клиент не отправляет готовое время круга. Пароли хешируются scrypt с уникальной солью; сессии ограничены сроком, cookie HttpOnly; предусмотрены проверки Origin и ограничения запросов/сообщений.

Один серверный процесс, комнаты максимум по восемь участников. Производительность массовых комнат и публичная устойчивость под нагрузкой ещё не подтверждены. Нет восстановления пароля и подтверждения email. Столкновения игроков рассчитывает сервер. До публичного массового запуска потребуются HTTPS/WSS, постоянный диск, резервное копирование и нагрузочная проверка.
